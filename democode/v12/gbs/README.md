## 快速开始

### 场景1：用户想扮演某个角色对话
→ 使用 `skills/farewell-poem-roleplay/SKILL.md`
→ 参考 `00-游戏总览.md` 了解角色关系
→ 参考对应角色的OCR剧本了解详细剧情

### 场景2：用户想当DM主持游戏
→ 使用 `skills/farewell-poem-dm/SKILL.md`
→ 参考 `10-组织者手册-OCR.txt` 了解完整流程
→ 参考各线索文件夹准备道具

### 场景3：接入4B小模型
→ 使用 `skills/farewell-poem-4b/SKILL.md`
→ 参考 `00-4B模型参考.md`
→ 使用 `系统提示词/` 文件夹中的提示词模板

## 小模型接入说明

4B小模型推荐配置：
- 系统提示词：使用 `系统提示词/` 中的模板
- 参考文档：使用 `00-4B模型参考.md`（精简版）
- Skill：使用 `farewell-poem-4b/SKILL.md`
- 上下文窗口：建议4K-8K tokens
- 温度：0.7-0.9（保持创造性）
