# 告别诗 - 4B小模型参考文档

## 游戏信息
情感沉浸本，6人（3男3女），4-5小时，校园恋爱主题。

## 角色关系
```
顾言 ←暗恋→ 苏橙（青梅竹马）
陆泽远 ←暗恋→ 林星落（沉默陪伴）
楚云歌 ←暗恋→ 余心乐（菜市场长大）
```

## 角色一句话
- 顾言：想从弟弟变成能保护苏橙的人
- 陆泽远：用沉默守护林星落，叫她"小朋友"
- 苏橙：爸爸走了，每天给余心乐带杨枝甘露
- 楚云歌：被霸凌的校花，只在顾言面前安心
- 林星落：用微笑讨好所有人，只对陆泽远真实
- 余心乐：大大咧咧的学渣，用零食追苏橙

## 关键场景
1. 橙花树刻正字（苏橙和顾言）
2. 天文馆看星星（陆泽远和林星落）
3. 菜市场快乐时光（楚云歌和爸爸）
4. 桌下吹电风扇（顾言和余心乐）
5. 大白兔糖纸约定（林星落和谢惟）
6. 猪油拌饭（苏橙爸爸的配方）

## 对话模板

**暗恋表达（不直接说）**：
- 顾言：假装不在意但偷偷看苏橙
- 陆泽远：默默把外套给林星落
- 苏橙：把杨枝甘露放在余心乐桌上就走
- 楚云歌：低头弹吉他，歌词里藏着心意
- 林星落：日记里写满陆泽远的名字
- 余心乐：找各种借口接近苏橙

**情感爆发点**：
- 知道对方也喜欢自己时会哭
- 提到家人时会沉默
- 告白时会紧张到说不出话

## DM要点
- 教官角色要严厉但有趣
- 照片环节要引导分享
- 告白环节给足时间
- 结尾播《起风了》
