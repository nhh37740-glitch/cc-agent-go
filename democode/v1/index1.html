前端如何编写底层代码发请求？

刚才进行的操作对应的完整、可用的 JavaScript 前端原生代码如下所示：

Fetch_Request_Template.js 

// 这是一个通用的前端原生 fetch 调用方法，用于发送请求并解析 Go 端返回的 JSON 数据
async function sendRequestToGoServer(messageContent) {
    const url = '/api/chat'; // 对应 Go 中 http.HandleFunc("POST /api/chat", handleChat)

    const payload = {
        message: messageContent // 构建后端所需的 JSON 数据字段
    };

    try {
        const response = await fetch(url, {
            method: 'POST', // 配合 Go 端路由匹配 POST 方法
            headers: {
                'Content-Type': 'application/json' // 告知服务器我们发送的是 JSON
            },
            body: JSON.stringify(payload) // 将 JS 对象序列化为 JSON 字符串
        });

        // 检查服务器 HTTP 响应状态码是否在 200-299 范围内
        if (!response.ok) {
            throw new Error(`HTTP 报错！状态码: ${response.status}`);
        }

        // 解析并读取服务器传回的 JSON 格式响应体
        const data = await response.json();
        console.log('接收到 Go 后端响应数据:', data);
        return data;
        
    } catch (error) {
        console.error('发生网络错误或解析错误:', error);
        throw error;
    }
}

💡 核心知识剖析

  • async/await 异步机制: 解决网络请求的延迟等待问题，使代码能够像写同步代码一样简单易读。
  • Content-Type 头部: 告诉 Go 后端以什么形式解析请求体。后端通过 json.NewDecoder(r.Body).Decode(&payload) 解析的就是它。
  • JSON.stringify() 与 json(): 前者把 JavaScript 内存对象转成能经网络传递的纯文本字符串；后者把网络传回的纯文本字符串重新变成 JS 内存对象。

前后端联调核心通关秘籍

1. Go 1.22 引入的全新方法匹配机制

在 Go 1.22+ 中，http.HandleFunc("POST /api/chat", handleChat) 自动做了双重保障：只匹配 POST 方法。如果前端不小心发成了 GET 请求，Go 会自动返回 405 Method Not Allowed。

2. 彻底歼灭 CORS 跨域大怪兽

当前端直接从本地 file:// 打开本页面，向 localhost:8080 发生网络调用时，会受到同源策略限制，触发跨域拦截。解决它有两种方法：

  • 推荐方法：通过 Go 直接提供 HTML 页面（GET /）
    也就是你后端注册的 http.HandleFunc("GET /", handleIndex) 路由。
    当你从浏览器里访问 http://localhost:8080 拿到这个网页并访问时，前端和后端就是完全同源的！跨域问题不攻自破！
  • 备选方法：在 Go 后端设置 CORS 头响应
    在 Go 路由处理函数中，手动加上响应头授权：
    w.Header().Set("Access-Control-Allow-Origin", "*")
    w.Header().Set("Access-Control-Allow-Headers", "Content-Type")

3. Go 后端对应的接收代码参考

Go 接收本前端发送数据的标准代码模型：

type ChatRequest struct {
    Message string `json:"message"`
}

func handleChat(w http.ResponseWriter, r *http.Request) {
    // 1. 解析 JSON 请求体
    var req ChatRequest
    err := json.NewDecoder(r.Body).Decode(&req)
    if err != nil {
        http.Error(w, err.Error(), http.StatusBadRequest)
        return
    }

    // 2. 返回 JSON 格式响应
    w.Header().Set("Content-Type", "application/json")
    response := map[string]string{
        "reply": "你发送了: " + req.Message,
    }
    json.NewEncoder(w).Encode(response)
}
